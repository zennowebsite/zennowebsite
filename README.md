## 🧭 Como funciona

Um processo simples, transparente e acompanhado de perto em cada etapa.

| | Etapa | O que acontece |
|:-:|---|---|
| **1** | **Entendemos o seu negócio** | Você conta seus objetivos e necessidades. Alinhamos as ideias e definimos o projeto. |
| **2** | **Desenvolvemos o site** | Criamos o layout e a implementação, com atenção ao visual, à navegação e aos dispositivos móveis. |
| **3** | **Revisamos juntos** | Você avalia o projeto e pede os ajustes previstos. Publicamos após a sua aprovação. |
| **4** | **O site vai ao ar** | Publicamos o site para que seu negócio seja encontrado na internet. |
